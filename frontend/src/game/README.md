# 游戏 UI 架构

游戏页由框架提供会话状态、能力接口和安全动作桥接，世界包提供真正的 HTML/CSS/JavaScript 页面。

世界包 UI 运行在 `sandbox="allow-scripts"` iframe 中，通过 `window.world` SDK 读取状态并请求宿主动作。页面可以自由组织 DOM、样式和交互，但不能直接访问网络、文件系统或宿主进程。

框架层负责：

- 维护会话、消息、属性、地图和输入状态；
- 将快照通过 MessageChannel 发送给世界页面；
- 校验并执行提交消息、世界逻辑、存储、平台能力等动作；
- 在导入和编辑阶段报告 HTML、CSS、能力声明与兼容性诊断。

世界包作者只需在压缩包中提供桌面/移动 HTML、CSS、资源和可选逻辑声明，不需要使用额外的 UI DSL 或开发工具链。
