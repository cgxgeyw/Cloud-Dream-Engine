## 推送成功（`0dd7cf4..78df89c`，7 个提交）

浏览器能访问 GitHub 但 git push 失败的原因**不是网络不通**：用 `git ls-remote` 测试小请求**成功返回 HEAD**，说明代理链路本身没问题。失败发生在**持续上传阶段**（`send-pack: unexpected disconnect while reading sideband packet`）或间歇性 TLS 握手失败。

**有效的推送参数组合**（前几次失败是默认参数）：
```bash
timeout 180 env GIT_TERMINAL_PROMPT=0 git \
  -c credential.helper= \
  -c http.proxy=http://127.0.0.1:7897 -c https.proxy=http://127.0.0.1:7897 \
  -c http.version=HTTP/1.1 \
  -c http.lowSpeedLimit=0 -c http.lowSpeedTime=999 \
  -c http.postBuffer=524288000 -c core.compression=0 \
  push --progress "https://<user>:<token>@github.com/<owner>/<repo>.git" main
```
关键三项：`http.version=HTTP/1.1`（强制协议）、`lowSpeedLimit=0/lowSpeedTime=999`（**关掉低速超时**，默认会在慢速上传时把连接掐掉，这是"unexpected disconnect"的主因）、`postBuffer` 调大。41 个对象 26.56 KiB，4.43 MiB/s 一次过。

诊断顺序值得记住：**先 `ls-remote` 判断是链路问题还是大流量问题**。小请求成功 → 加大超时/关低速限制重试；小请求也失败 → 才是代理/节点问题需要用户切节点。

## 新增 `svg` / `canvas` 节点（声明式图形）

起因是评估「恶魔轮盘」世界包时的结论：UI 节点只有 12 种、没有 svg/canvas，图形只能靠 CSS 或图片，摆轮盘/血条/图表很别扭。

**路线选择（用户拍板）**：两者都走**声明式**，不开注入口。
- `svg` = 图元子节点（`svg_circle/rect/line/path/polygon/text`），不写裸 `<svg>` 字符串
- `canvas` = `ops` 绘制指令数组（`clear/rect/circle/arc/line/text/image`），不执行作者脚本

**安全立场**：项目至今**没有任何 `dangerouslySetInnerHTML`，也没有 DOMPurify**，这是刻意的（唯一例外是 Streamdown 内部处理消息 Markdown）。新增节点必须维持这条线——裸标记字符串方案需要先引入净化器，被否掉。

**改动落点（改节点要同步这 6 处，漏一处就白测）**：
1. `frontend/src/data/gameUi/types.ts` — 类型 + 联合类型加 `svg` / `canvas`
2. `frontend/src/data/gameUi/parser.ts` — **三处**：`normalizeLayoutNodeV2` 分支、`validateLayoutNodeV2`白名单（第 1115 行那句报错文案）、以及类型专属校验分支
3. `frontend/src/components/GameUiRenderer.tsx` — `renderV2Node` 分派 + import
4. `frontend/src/components/GameUiGraphicNodes.tsx`（新建）— `SvgNodeView` / `CanvasNodeView`
5. `src-tauri/src/services/game_ui/mod.rs` — `validate_v2_node` 的 match 分支 + 两个新校验函数
6. 遍历 children 的地方要排除 svg 图元：`GameUiSandboxRuntime.tsx:417`、`game/utils.ts:620`

**三个踩坑**：
- **`parser.ts` 的 for_each 校验是 fall-through**（函数末尾，不是 `if type === "for_each"`）。新增类型若不写显式分支，会被当成 for_each 报「source must be a non-empty string」。
- **必填校验与默认归一化不能同时存在**：`view_box` / `width` / `height` 若在校验里要求必填，归一化里的默认值永远走不到（测试直接fallback 到默认文档）。要么都必填，要么都可选——选了后者。
- **Rust `r#"..."#` 里写 `"#ffffff"` 会提前终止字符串**（`"#` 序列）。含颜色值的测试 JSON 要用 `r##"..."##`。批量替换时小心误伤同文件既有的普通 `r#"` 测试。

**踩坑补充**：前端测试的模板字符串里写 `https://` 会被 jsonc-parser 当成行注释，导致 JSON 截断、解析静默走fallback。测试数据里避开 `//`。

## 平台能力边界：能做什么、不能做什么

用户问「框架能不能支撑某个玩法」时的现成结论，避免重复调研。**以下均已逐条核实代码位置**（2026-10-09）。

### 没有的能力（宿主级缺口，改世界包解决不了）

1. **没有 AI 自动回合**。`game_engine/` 下无 `auto_turn` / `npc_turn` / `autoReply` 任何实现。整个链路是单向的「玩家发言 → 模型回应」，**模型只在玩家输入后才说话**。要 AI 自己出招必须改回合调度器。
2. **没有骰子/随机数动作**。catalog 的 29 个动作里无 `roll`；世界 `logic.js` 里能用 `Math.random`，但只在玩家点按钮或事件触发时才跑，AI 回合里没有调用点。
3. **事件 handler 的返回值被丢弃**。`GameUiSandboxRuntime.tsx:312` 的 `dispatchWorldEvent` 里 `await invokeWorldLogic(...)` 结果没有接进 `setUiState`；协议里也没有 `set-ui-state` 消息类型，handler 调不到 UI 的 `set_state`。→ **事件只能写存储，不能回写 UI**，靠snapshot 重建顺带刷新会晚一拍。
4. **logic 无跨调用内存**。每次调用新建 Worker + `worker.terminate()`，超时被 `parser.ts:146` 硬钳在 5 秒上限。状态必须落盘（records/kv）。

### 具备的能力（世界包内即可实现）

- **动画完全可用**：世界 stylesheet 不过滤内容（只对 `.game-*` 未知名 class 报 warning），1 MiB 上限。`conic-gradient` + `@keyframes` + `transform: rotate()` 可画转盘。节点 `style` 字段支持 `{{$state.x}}` 插值（`resolveStyleRecord`）。
- **UI 节点类型原有 12 种**（`component / text / image / badge / button / checkbox / slot / when / for_each / absolute / stack / grid`），2026-10-09 已补上 `svg` 与 `canvas`（声明式，见上文）。此前无 svg/canvas，图形只能靠 CSS 或图片。
- **5种交互**：`choice / multi_choice / form / confirm / slider`（`director_interaction_kinds` 门控，不声明则导演既不下发也会丢弃已解析的 interaction）。
- **属性可读写**：`session` / `session_character` 作用域，导演能写（`session_attribute_updates` / `character_attribute_updates`），UI 能读（`attributes` / `attributes_by_owner` 在 `runtimeData` 里）。
- **UI 可绑定的运行时数据**：session / world / player / attributes / attributes_by_owner / attribute_items / messages / visible_characters / capabilities / ui_state / errors / side_tabs / scene_focus / latest_narration / draft_input / viewport。
- **kv 三级作用域**：`world`（缺省，跨存档共享）/ `session`（存档级）/ `character`（需characterId）。见 `resolveKvScope`。
- **logic 三个事件**：`session_start` / `turn_completed`（含本回合 messages）/ `interaction_answered`（仅首次）。
