## 三句话版本

1. **OAG 不是“世界书 + 事件日志 + 搜索”**：它是世界包定义的类型/属性/关系，加上事件、知识边界和逻辑查询。
2. **隔离不是过滤结果，而是先裁剪可见子图**：每个 actor 只能在自己的“场景围栏 + 知情围栏”内做遍历、聚合、否定。
3. **记忆是主观投影，事件是客观账本**：角色的 `memories` 只属于自己；事实是带 `asserted_by` 的 claim，不是绝对真理。

## 当前状态（2026-11-27）

- 记忆模式：世界编辑器 → 世界主控 → **运行方式 → 记忆模式**，默认 `Embedding 记忆`；可选 `历史对话`、`Embedding 记忆`、`OAG`。
- 三档都发送按消息 `witnesses` 过滤的最近 N 轮对话；非空 `recipients` 会进一步把私聊/耳语限制为说话人 + 收件人。
- 历史对话：只发送近期可见对话，不自动召回长期记忆或注入 OAG 投影。
- Embedding：在历史对话之外，按当前输入召回相关的历史对话、事件和总结。
- 固定桶总结：每 `memory_summary_interval_rounds` 回合（默认 10）一个桶（1-10、11-20……），桶内按场景拆条；只召回已经离开原文窗口、且所在桶已有总结的桶。原文窗口按桶对齐，避免边界重复或空洞。
- 总结提示词：角色用 `character_memory_summary_prompt`，主控全局总结用 `director_memory_summary_prompt`；世界编辑器可编辑，留空用内置默认，支持 `{{character_name}}`、`{{transcript}}` 等占位符。
- OAG：M1 的结构化存储、世界包本体、确定性回合写入、Debug 可见子图查询、分支/回滚/清理和世界包导入差异预览已落地；M2 投影与 `oag_query` 已接入角色与导演。OAG 与 Embedding/关键词召回互补使用，不关闭语义召回。
- 角色与导演的历史轮数默认 30；不设 token 预算/截断，低上下文模型通过降低轮数解决；已存在角色保留原值。

## M0 已落地范围（2026-11-26）

1. **逐消息记忆隔离**：`build_turn_entries()` 按每条消息自己的 `witnesses`、`recipients`、`scene_id` 写记忆；场景切换回合不再把旧场景输入写进新名册，耳语不再群发。
2. **事实 claim 化**：`memory_relations` 保存 `asserted_by`、`asserted_by_id`、`visibility`、`truth_status`、`witnesses_json`；多说话人合并时由 payload 覆盖模型自报来源，`truth_status` 强制为 `asserted`。
3. **actor 可见性**：`public` 全 actor 可见，`private` 仅说话人，`scene` 仅说话人或见证者；旧的无来源事实对 actor 失败关闭，导演/调试仍可读全图。矛盾失效只在同一 actor 可见范围内进行。
4. **知识库 audience**：文档支持 `public`、`director`、`character`；角色检索在 FTS、分块、嵌入和排序前过滤，旧文档默认 `public`，世界包导入导出保留 audience。
5. **分支/回滚一致性**：分支复制记忆、向量、总结区间、实体和事实，并重映射全部 ID；回滚快照包含总结区间，能清除快照后生成的旧桶异步总结，并还原事实来源和可见性。
6. **前端**：知识库资料编辑提供可见范围与角色选择器，桌面/移动端共用 audience 保存契约。

验证：Rust 全量 324 项测试、前端 52 项测试、TypeScript 检查与生产构建通过；知识库受众编辑已在浏览器中用 mock IPC 走通移动端保存流程。

## M2 投影阶段验证（2026-11-26）

- 角色与导演都从 `VisibleGraph` 的已裁剪视角生成单一 `oag_context`；最近对话仍只走 `chat_history`。
- 默认预算为角色 2400、导演 1800，按来源配额和模型渲染文本的 Unicode 字符数截断，不是真实 tokenizer 计数；完整 Debug 投影保留候选、选择与省略原因，但不进入模型预算或消息。
- 模型只接收紧凑的场景、相关实体、已知事实、世界关系、最近事件、相关记忆和导演摘要，并附带记忆使用契约；不接收内部 ID、来源字段、预算、trace 或完整投影 JSON。世界背景继续由独立 section 注入，不在 OAG 中重复。
- 覆盖同场景不同角色的私密事实、未来事实、延迟知识、私聊事件信封、事实去重、最终选择阶段的事件/记忆去重与预算截断测试；全局导演摘要只注入导演/作者，不进入角色投影。
- Embedding 模式保持原有向量/词法召回；OAG 模式同时执行该召回。两类内容合并到同一个记忆 section，并按正文跨层去重。
- 逻辑查询内核、Debug 查询面板和统一只读模型工具已交付；条件访问策略、Debug 投影专用面板和独立事实抽取仍属于后续阶段。

## 提示词注入编排验证（2026-11-27）

- 默认角色顺序为世界背景、角色背景、角色规则、角色基础属性、OAG 与语义记忆、世界运行时上下文、角色运行时上下文、可见角色/场景、对话历史、旁白提示词、玩家输入、返回格式、事实记忆规则。
- 玩家配置的 `character_prompt_order` 始终优先；未知与重复 ID 被忽略，未指定项按默认顺序补齐。导演继续使用独立的导演顺序。
- 当前场景严格匹配投影请求的场景 ID，参与者从 OAG 场景成员表读取；找不到当前场景时不会退到其他场景。关系、当前场景和演员相关内容优先，最近变化优先。
- 角色投影、导演投影、语义召回和提示词顺序专项测试通过。真实模型端到端效果仍待作者在世界中验证。

## M2 逻辑查询验证（2026-11-26）

- `resolve/entity/find/traverse/aggregate/absence/knows/timeline` 八种查询均基于已裁剪的 `VisibleGraph`，不先查全图再过滤结果。
- 多跳最多 3 跳，只使用世界包声明的关系、对称关系和反向关系，并避免环路；聚合支持计数、去重计数、求和、平均、最小、最大及三种分组。
- 否定结果明确标记为“当前可见记录中没有匹配”，不推断隐藏信息或从未发生；知情查询限制角色只能查自己，耳语来源事件只返回脱敏信封。
- Debug 面板已支持全部查询参数；Rust 374 项库测试、前端 TypeScript 检查、52 项测试与生产构建通过。
- 浏览器 mock IPC 已验证基础查询、多跳步骤增删、聚合分组、否定条件校验、角色知情权限、时间线提及过滤与请求字段清理；524px 窄视口无横向溢出。应用内浏览器未提供可见截图表面，因此未生成截图。

## 统一模型工具验证（2026-11-26）

- OAG 模式下，导演和普通角色都通过现有工具机制获得只读 `oag_query`，通过 `op` 复用八种查询；Embedding 模式不提供该工具，角色预览与实际请求使用同一套工具能力生成。
- 世界、存档、视角、当前回合和节点上限由后端固定；模型不能覆盖 `as_of_turn` 或读取退休记录。
- 导演可收到正常查询结果和参数错误回执；工具不会落入自定义 MCP 执行器，活动记录显示“查询世界关系”。
- 本轮新增 7 项定向测试通过；完整 Rust 库测试 381 项通过。真实模型端到端工具调用尚未验证。
