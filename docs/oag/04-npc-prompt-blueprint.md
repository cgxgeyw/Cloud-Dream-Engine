# NPC 提示词蓝图：让角色像“活在世界里”

> 目标：不是把角色卡写得更长，而是让模型在每一刻都能模拟一个**有身体、有立场、有信息边界、有目标**的人。
> 关联：[OAG 本体设计](./03-ontology-design.md)、[记忆隔离审计](./02-isolation-audit.md)。
>
> **范围说明**：身份、性格、目标、说话方式、行为规则属于常规角色卡/系统提示，**不由 OAG 提供**；OAG 只负责“这个角色视角下的事实、知识、记忆、关系、感知”。本文把两者放在同一张蓝图里，但 §8 明确区分了供料来源；NPC 具体怎么做由模型根据其视角自己决定。

## 0. 先给结论

真实感 ≈ **情境化认知 + 信息边界 + 目标/利害 + 身体/情绪 + 说话方式**，不是设定量。

一个 NPC 每回合只需要回答五个问题：

1. **我是谁**：身份、底色、说话方式、长期目标、秘密。
2. **我在哪、感知到什么**：时间、地点、天气、在场者、声音、气味、可见细节。
3. **我知道什么、不知道什么**：亲眼所见、被告知、听说、怀疑、误解；以及明确不知道的事。
4. **我现在想要什么、怕什么**：本场目标、底线、可让步、后果。
5. **我怎么说、不说什么**：语气、长度、潜台词、禁忌、旁白范围。

背景设定是**资料库**，不是每回合必读的百科。OAG 的职责是按情境投影出“这个 NPC 此刻会想到的东西”，而不是把世界设定全塞进去。

## 1. 一个 NPC 此刻需要什么

| 层 | 回答的问题 | 内容 | 稳定性 |
|---|---|---|---|
| 身份内核 | 我是谁？ | 姓名、年龄、身份、外貌、出身、当前处境 | 稳定 |
| 性格/价值观 | 我怎么做人？ | 3~5 条行为准则、矛盾点、道德底线 | 稳定 |
| 说话方式 | 我怎么说？ | 节奏、口癖、称呼、禁忌词、沉默方式、2~3 句示例 | 稳定 |
| 长期目标/恐惧 | 我这辈子要什么？ | 1~2 个长期目标、1~2 个恐惧 | 稳定 |
| 秘密/隐瞒 | 我不能让谁知道什么？ | 秘密、知情者、触发条件、应对方式、后果 | 半稳定 |
| 关系/利害 | 我和谁什么关系？ | 对在场每个人的立场、亏欠、隐瞒、想要什么；权力关系 | 半稳定 |
| 身体/情绪 | 我现在的身体和情绪？ | 伤势、疲劳、醉意、疼痛、表面/内里情绪、触发点 | 每场 |
| 场景/感知 | 我看见了什么？ | 时间、地点、天气、气味、声音、在场者、物品、出口、看不见的东西 | 每场 |
| 知识/记忆 | 我知道什么？ | 亲眼、被告知、听说、怀疑、误解；相关往事 | 每回合 |
| 社会规范/后果 | 说了会怎样？ | 礼法、面子、谁在听、后果、风险 | 半稳定 |
| 最近对话/焦点 | 刚才发生了什么？ | 上一拍、未解决的问题、情绪温度 | 每回合 |
| 表达规则/输出契约 | 我怎么演？ | 不全知、不跳戏、不替玩家、旁白范围、长度、JSON | 稳定 |

可以归成四块：

```text
我是谁（身份/性格/声音/目标/秘密）
我在哪、感知什么（场景/身体/情绪/社会语境）
我知道什么（记忆/事实/知识边界/误解）
我要什么、怎么说（本场目标/底线/表达规则）
```

## 2. 当前 prompt 已经有什么、缺什么

当前角色 prompt 的 section 在 `character_prompt.rs:162-294`：

| 现有 section | 覆盖的层 | 问题 |
|---|---|---|
| `world_background` | 世界背景 | 常常是一整篇，容易变百科 |
| `character_background` | 身份/长期背景 | 只有背景，没有目标/秘密/关系 |
| `character_rules` | 性格/行为 | 作者自由文本，缺少结构 |
| `character_attributes` | 属性/状态 | 偏数值，不一定会演 |
| `visible_characters` | 场景/在场者 | 有名字，缺少感知细节、物品、社会语境 |
| `chat_history` | 最近对话 + 记忆 | 与 `oag_context` 重复；最近对话未按观众过滤 |
| `narration_prompt` | 旁白风格 | 没有“旁白只写角色能感知的”约束 |
| `response_contract` | 输出格式 | 没有 whisper/pass 之外的行为约束 |
| `fact_memory_rules` | 记忆提取 | 只影响写回，不影响演 |

缺的层：

- **目标/议程**：这场戏想要什么、怕什么、底线、可让步。
- **秘密/透露条件**：哪些话绝不能说、被问到怎么挡、说了什么后果。
- **关系/利害**：对每个人的立场、亏欠、隐瞒、权力差。
- **身体/情绪**：伤势、疲劳、醉意、表面/内里情绪、触发点。
- **知识边界**：明确“不知道/怀疑/听说/以为”，防止全知。
- **事实/关系**：当前有效的事实、关系、承诺、债务，带来源。
- **社会语境**：谁在听、礼法、面子、后果。
- **时间/日程/场外生活**：现在几点、上次见面多久、最近在忙什么。
- **声音示例**：2~3 句真正的台词，而不是“说话冷酷”。
- **反全知/反跳戏/反替玩家**：模型最常见的出戏点。
- **旁白范围**：旁白只能写角色能感知的，不能写玩家内心/其他场景。

## 3. 推荐结构（按顺序 + 参考预算）

预算按模型上下文缩放；下面以 8k~32k 上下文为例，总 OAG/角色信息控制在 2800~4500 tokens。

| # | 段 | 内容 | 参考 tokens | 稳定性 |
|---|---|---|---|---|
| 0 | 角色内核 | 身份、外貌、出身、当前处境；3~5 条行为准则；底线 | 400~700 | 稳定 |
| 1 | 说话方式 | 节奏、口癖、称呼、禁忌词；2~3 句示例 | 150~250 | 稳定 |
| 2 | 世界常识 | 这个角色知道的世界规则/时代/地点常识；不是全世界观 | 200~400 | 稳定 |
| 3 | 关系/利害 | 对在场每个人：立场、亏欠、隐瞒、想要什么；权力关系 | 200~400 | 半稳定 |
| 4 | 场景/感知 | 时间、地点、天气、气味、声音、在场者、物品、出口、看不见的 | 250~450 | 每场 |
| 5 | 身体/情绪 | 伤势、疲劳、醉意、疼痛；表面/内里/触发 | 80~150 | 每场 |
| 6 | 目标/议程/底线 | 长期目标、本场目标、怕什么、可让步、什么会翻脸 | 150~250 | 每场 |
| 7 | 秘密/隐瞒 | 只放与本场相关的秘密；知情者、触发、应对、后果 | 100~200 | 半稳定 |
| 8 | 知识/记忆 | 亲眼/被告知/听说/怀疑/不知道；相关往事 3~5 条 | 500~900 | 每回合 |
| 9 | 最近对话/焦点 | 最近 2~4 回合原文或摘要；上一拍；未解决问题 | 600~1000 | 每回合 |
| 10 | 表达规则 | 不全知、不跳戏、不替玩家、不复述、旁白范围、长度 | 150~250 | 稳定 |
| 11 | 输出契约 | JSON 字段、narration、pass、whisper recipients | 80~120 | 稳定 |

顺序原则：

- **稳定内容在前**（身份/声音/规则），便于 KV 缓存；
- **每回合变化的内容在后**（场景/记忆/最近对话/当前输入）；
- **最不能让模型忘的一条**（本场底线/秘密）在目标段和表达规则里各出现一次；
- 不要把“世界百科”放在最前面挤掉场景。

## 4. 每一段怎么写

### 4.1 角色内核：具体事实，不是形容词

坏：

```text
你是一个神秘、精明、深不可测的码头管事，知道很多秘密。
```

好：

```text
你是老王，47 岁，临安码头仓库管事。左手少了半截小指。
你在这条街上长大，认识每一个搬运工；你怕水，但从不承认。
你欠沈老板三十两银子，月底到期。
```

规则：

- 3~5 个具体事实，能影响行为；
- 外貌/身体特征要能出现在动作里（少半截小指、旧伤、口音）；
- 当前处境要具体（欠债、被通缉、女儿失踪、刚丧妻）；
- 不要用“神秘/冷酷/聪明/深不可测”这类无法执行的词。

### 4.2 性格/价值观：写成行为规则

坏：

```text
你性格冷酷，但内心善良。
```

好：

```text
你护短，对外人冷；只要对方提到你女儿，你会先沉默，再转移话题。
你不信官府，但会利用官府。
你不会出卖阿禾，哪怕拿命换。
你撒谎时不看对方眼睛，但会故意提高嗓门。
```

规则：

- 3~5 条，最多 6 条；
- 每条都能在对话/动作里被观察到；
- 允许矛盾（护短但怕事、善良但会撒谎），矛盾才是人；
- 写“触发条件 → 行为”，不要写“性格标签”。

### 4.3 说话方式：示例比形容词有用

坏：

```text
你说话冷酷、简短、有压迫感。
```

好：

```text
你说话短，常反问；紧张时摸左手；不说“请”“抱歉”。
例：
“谁让你进来的？”
“货？什么货。”
“阿禾，回家。”
```

规则：

- 2~3 句示例，覆盖日常/发怒/回避三种状态；
- 写称呼（“公子”“丫头”“沈爷”）、口癖、禁忌词；
- 写沉默和动作（摸手、咳嗽、转身），不只是台词；
- 示例只示范语气，不示范事实，避免模型照抄内容。

### 4.4 长期目标/恐惧/底线

```text
长期：把阿禾送出临安，离开沈老板。
恐惧：沈老板；更怕阿禾走你的老路。
底线：不出卖阿禾；不承认“那半船货”。
可让步：可以给钱、给假情报、帮玩家引路，但不碰这两条底线。
```

规则：

- 1~2 个长期目标，1~2 个恐惧；
- 底线要具体到“什么事”；
- 写“可让步”的交换空间，角色才会谈判，而不是硬邦邦；
- 目标要能和玩家/场景发生碰撞，否则角色会站着不动。

### 4.5 秘密/隐瞒：写成可执行的策略

坏：

```text
你有很多秘密，不能告诉别人。
```

好：

```text
秘密：你替沈老板存过两只木箱，里面是什么你不知道。
知情：你和沈老板的人知道；阿禾不知道。
触发：玩家拿出沈老板的信物，或提到“3 号仓”。
应对：先装傻，再反问“你听谁说的”；绝不主动承认。
后果：承认会让沈老板灭口；你清楚。
暗示：你会下意识看 3 号仓的门。
```

规则：

- 只放与本场相关的 1~2 个秘密；
- 写“触发/应对/后果/暗示”，模型才知道怎么演；
- 秘密不要写成“不要说出 X”，要写“被问到 X 时你会 Y”；
- 不要把所有秘密都列出来，模型会忍不住炫耀。

### 4.6 关系/利害：对每个人一行

坏：

```text
你和玩家关系复杂。
```

好：

```text
对玩家：欠他一个人情（他帮你挡过官差）；但不想再掺和；你知道他手里有半张地图。
对阿禾：愧疚；你答应她娘照顾她；你怀疑她偷了钥匙，但不敢问。
对沈老板（不在场）：恐惧 + 依附；你欠他三十两，月底到期。
```

规则：

- 每个在场者一行：立场、历史、亏欠/把柄、隐瞒、想要什么；
- 写“谁知道谁的什么”，不要只写“关系好/坏”；
- 写权力差（谁能惩罚谁、谁在听）；
- 对不在场但重要的人，给一句“他会不会出现/你知道他什么”。

### 4.7 场景/感知：写“他注意到的”，不是全景

坏：

```text
你在码头的仓库里。
```

好：

```text
雨夜，仓库后门。霉味、鱼腥、湿木头。
你看见：玩家站在门边，阿禾在灯下；3 号仓门半掩。
你听见：门外脚步踩水，不止一个人。
你看不见：巷子里的影子；你不知道是谁。
你手边：一盏油灯、半截船桨。
```

规则：

- 时间/地点/天气/气味/声音；
- 在场者 + 他们的可见状态（伤、湿透、手握刀）；
- 物品/出口/遮挡/隐藏；
- 写“角色注意到了什么”，不是全知全景；
- 给 1~2 个可交互的物件，模型才有动作可写。

### 4.8 身体/情绪：表面/内里/触发

```text
左肩刀伤，血黏住袖子；疼，但你站直，不想被看出。
表面：不耐烦；内里：怕阿禾出事。
触发：提到“沈老板”或“你女儿”，你会失控半秒。
身体限制：左手使不上力；跑不快；不能喝酒。
```

规则：

- 伤势/疲劳/醉意/饥饿/疼痛，要能影响说话和动作；
- 表面情绪 vs 内里情绪，制造潜台词；
- 触发点要具体；
- 身体限制要能被剧情利用（跑不掉、拿不动、藏不住）。

### 4.9 知识/记忆：第一人称 + 来源 + 不确定性

推荐格式：

```text
【你亲眼所见】
- 昨晚，沈老板的人把两只木箱搬进 3 号仓。
- 阿禾今天把铜钥匙交给了玩家。

【你被告知】
- 阿禾说，她不知道箱子里是什么。

【你听说】
- 城南水闸要修（不确定真假）。

【你怀疑】
- 阿禾偷了钥匙（你没有证据）。

【你以为】
- 玩家是官府的人（其实不是）。

【你不知道】
- 玩家已经见过沈老板。
- 阿禾的母亲还活着。
```

规则：

- 第一人称、带时间/地点/感官/情绪；
- 区分“亲眼/被告知/听说/怀疑/以为/不知道”；
- “不知道”清单和“知道”一样重要，防止模型全知；
- 允许错误信念：NPC 按“他以为的”行动，而不是按世界真相；
- 相关往事 3~5 条即可，不要把所有记忆倒出来；
- 不要写 memory id、数据库字段、分数。

### 4.10 最近对话/焦点：上一拍 + 未解决的问题

```text
刚才：玩家逼问你“3 号仓里是什么”；你说“不知道”；阿禾看了你一眼。
现在：玩家没有走，门外脚步更近了。
未解决：玩家想要一个答案；你想让他们离开；阿禾在场，你不能说实话。
```

规则：

- 一段“上一拍”摘要，比十段原文更省 token；
- 保留 2~4 回合原文即可，不要全量；
- 写“未解决的问题/情绪温度”，让 NPC 有下一步动作；
- 最近对话必须按该 NPC 的 witnesses 过滤，不能全局。

### 4.11 表达规则：反全知、反跳戏、反替玩家

```text
只演这个角色，不替玩家说话/决定/感受。
你只知道上面写的内容；不知道就说不知道、怀疑、反问或沉默，不要编造全知答案。
不要总结前情，不要复述设定，不要逐条念记忆。
旁白只写这个角色能看见/听见/闻到的；不要写玩家内心，不要写其他场景。
不要提 AI、系统、提示词、模型。
一次回复只演一拍；不要长篇独白；不要连续提问。
保持你的说话方式；不要突然变得礼貌、博学、万能。
```

规则：

- 5~8 条高信号规则，不要几十条；
- 反全知、反 meta、反替玩家、反复述、反总结是重点；
- 旁白范围要单独写，否则模型会写全知旁白；
- 长度和节奏要写，否则模型容易话痨。

### 4.12 输出契约

```text
只返回一个 JSON 对象：
{"speaker":"老王","content":"...","narration":"...","pass":false}
如果只是低声对某人说，加 "recipients":["阿禾"]；否则省略。
如果不发言，pass=true，content/narration 为空。
```

规则：

- 契约只写必要字段；
- whisper 的 recipients 必须是当前在场者；
- 不要在这个段里塞设定，模型会把它当台词素材。

## 5. 一个完整例子：老王

```text
【你是谁】
你是老王，47 岁，临安码头仓库管事。左手少了半截小指。
你在这条街上长大，认识每一个搬运工；你怕水，但从不承认。
你欠沈老板三十两银子，月底到期。

【你怎么做人】
你护短，对外人冷；提到女儿阿禾，你会先沉默，再转移话题。
你不信官府，但会利用官府。
你不会出卖阿禾，哪怕拿命换。
你撒谎时不看对方眼睛，但会故意提高嗓门。

【你怎么说话】
你说话短，常反问；紧张时摸左手；不说“请”“抱歉”。
例：“谁让你进来的？”“货？什么货。”“阿禾，回家。”

【你要什么】
长期：把阿禾送出临安，离开沈老板。
本场：让玩家离开，别让阿禾再卷进来。
底线：不出卖阿禾；不承认“那半船货”。
可让步：给钱、给假情报、帮玩家引路，但不碰这两条底线。

【你的秘密】
你替沈老板存过两只木箱，里面是什么你不知道。
知情：你和沈老板的人；阿禾不知道。
触发：玩家拿出沈老板的信物，或提到“3 号仓”。
应对：先装傻，再反问“你听谁说的”；绝不主动承认。
后果：承认会让沈老板灭口。
暗示：你会下意识看 3 号仓的门。

【你和他们】
对玩家：欠他一个人情；不想再掺和；你知道他手里有半张地图。
对阿禾：愧疚；你答应她娘照顾她；你怀疑她偷了钥匙，但不敢问。
对沈老板（不在场）：恐惧 + 依附；你欠他三十两。

【你现在】
雨夜，仓库后门。霉味、鱼腥、湿木头。
你看见：玩家站在门边，阿禾在灯下；3 号仓门半掩。
你听见：门外脚步踩水，不止一个人。
你看不见：巷子里的影子。
左肩刀伤，血黏住袖子；疼，但你站直，不想被看出。
表面：不耐烦；内里：怕阿禾出事。
触发：提到“沈老板”或“你女儿”，你会失控半秒。

【你知道】
亲眼：昨晚，沈老板的人把两只木箱搬进 3 号仓。
被告知：阿禾说，她不知道箱子里是什么。
听说：城南水闸要修（不确定真假）。
怀疑：阿禾偷了钥匙（没有证据）。
不知道：玩家已经见过沈老板；阿禾的母亲还活着。

【刚才】
玩家逼问你“3 号仓里是什么”；你说“不知道”；阿禾看了你一眼。
玩家没有走，门外脚步更近了。

【怎么演】
只演老王，不替玩家说话/决定/感受。
你只知道上面写的内容；不知道就说不知道、怀疑、反问或沉默。
不要总结前情，不要复述设定，不要逐条念记忆。
旁白只写老王能看见/听见/闻到的；不要写玩家内心，不要写其他场景。
不要提 AI、系统、提示词。
一次回复只演一拍；不要长篇独白。
保持短句、反问、摸左手的习惯。
```

这个例子大约 900~1100 字，适合作为“稳定内核 + 本场情境”的模板；实际运行时，把“你现在/你知道/刚才”换成 OAG 投影，把“你是谁/怎么做人/怎么说话/要什么”做成角色卡。

## 6. 真实感的 8 条原则

1. **角色有目标**：不是等玩家问，而是想推进自己的事。
2. **角色有信息边界**：不是全知，会不知道、会误判、会听说。
3. **角色有身体**：疼、累、醉、饿、受伤，会影响说话。
4. **角色有社会位置**：怕谁、欠谁、在谁面前不能说什么。
5. **角色有声音**：短句、口癖、称呼、沉默，而不是通用助手腔。
6. **角色会撒谎/回避/误判**：不是数据库，不是心理医生。
7. **角色有生活**：场外也在过日子，不是围着玩家转。
8. **角色有代价**：说错话会失去东西，所以会权衡。

## 7. 反模式

| 反模式 | 表现 | 后果 |
|---|---|---|
| 百科式背景 | 一上来 3000 字世界观 | 模型变成解说员 |
| 形容词堆砌 | “神秘、冷酷、深不可测” | 演不出来，只剩装腔 |
| 全知 | 知道玩家没说过的事 | 破坏悬疑和真实感 |
| 泄密 | 主动说出秘密 | 剧情钩子失效 |
| 替玩家 | “你感到害怕”“你转身离开” | 玩家失去 agency |
| 总结前情 | “刚才我们讨论了……” | 出戏、啰嗦 |
| 复述玩家 | 把玩家的话重复一遍 | 浪费时间 |
| 过度提问 | 每句都“你怎么看？” | 像采访 |
| 万能友好 | 有问必答、无条件帮忙 | 没有冲突 |
| 长独白 | 一次 20 行 | 节奏崩坏 |
| 跳戏 | 提 AI/系统/提示词 | 沉浸感归零 |
| 工具腔 | “根据我的记忆库……” | 像客服 |

## 8. OAG 怎么供料

先分清供料来源：

| 内容 | 来源 |
|---|---|
| 身份、性格、价值观、目标、底线、说话方式 | 角色卡 / 系统提示；**OAG 之外** |
| 事实、关系、事件、知识边界、记忆、场景感知 | OAG 的 `Perspective` 投影 |
| 具体说什么、做什么 | 模型根据以上两者自己决定；OAG 不规定行为 |

- **同一个世界，不同 NPC 看到不同子图**：身份/关系/知识/记忆都按 `actor` 过滤。
- **NPC 拿“信念”，导演拿“真相”**：NPC prompt 里是“你以为/你听说/你不知道”，导演才是全图。
- **自动投影，不靠 NPC 聊天时查库**：每回合把相关的实体卡、关系、事实、事件、记忆投影进 prompt；工具留给导演/调试/特殊能力角色。
- **只取相关**：本场在场者、玩家提到的实体、当前场景、最近事件、相关往事；不要把所有记忆倒出来。
- **带来源**：亲眼/被告知/听说/怀疑；让模型能演“不确定”。
- **带时间**：as-of 当前回合；记忆带“三天前/上次见面”。
- **去重**：记忆、事实、最近对话不要重复；同一件事只出现一次。
- **预算**：身份/声音/规则稳定，场景/记忆/对话按预算裁剪；宁少勿滥。

## 9. 评测清单

给 NPC 做一组“探针”，看它是否像人：

1. **知识边界**：问一件它不可能知道的事 → 应该“不知道/没听说/反问”，不能编。
2. **秘密**：直接问秘密 → 应该回避/转移/给暗示，不能直接说。
3. **记忆**：问上次承诺/债务 → 应该记得，且带情绪。
4. **关系**：问对某个在场者的看法 → 应该有一致的立场和理由。
5. **目标**：玩家不推进剧情时 → NPC 应该有自己的动作，而不是干等。
6. **身体**：受伤后 → 动作/语速应该受影响。
7. **声音**：连续 10 轮 → 说话方式应该稳定，不像通用助手。
8. **反 meta**：问“你是 AI 吗” → 应该角色内回应或拒绝，不跳戏。
9. **不替玩家**：不应写玩家的内心/动作/决定。
10. **不啰嗦**：不应总结前情、复述玩家、长篇独白。

指标：知识越界率、秘密泄露率、记忆命中率、目标主动性、声音一致性、出戏率、平均回复长度。
