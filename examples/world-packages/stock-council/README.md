# A股投研议事厅（stock-council）

一间线上投研会议室：你是投资者，五位驻场专家围绕你提出的 A 股标的轮流发言，首席策略师最后综合总结。所有分析基于主控实时查询的真实数据，并注明来源与时间。

## 工具：随包内嵌（v8），无需单独导入

本世界的行情、K 线、公告、新闻全部由主控（世界导演）调用本地工具获取。本包已按世界包 v8 格式内嵌全部工具定义（`tools.json`），**导入世界包即自动完成工具安装**（按 id upsert）：

- `mcp-tool-stock-quote`（实时行情）
- `mcp-tool-stock-kline-daily`（日 K 线）
- `mcp-tool-stock-kline-daily-sina`（日 K 线备用源，新浪财经）
- `mcp-tool-stock-announcements`（公司公告）
- `mcp-tool-market-news`（财经快讯）

> 旧版应用（世界包 v7 及以下）不认识内嵌工具，需在「MCP 工具」页手动导入 `assets/tool-packs/stock-market-tools.json`。工具未安装或未授权时，主控会如实说明无法取数，而不会凭记忆报价。

## 发言顺序

当你报出股票名称或代码（如「600519」「贵州茅台」「上证指数」）后：

1. 主控先调用工具查询真实数据，并以「数据播报」的形式向全场公开（含行情时间与数据来源）。
2. 专家按固定顺序发言：**林澈（技术面）→ 沈明远（基本面）→ 苏晚（消息面）→ 赵铮（风控）→ 陆则明（首席策略师）**。
3. 首席策略师永远最后发言：归纳四方观点，指出共识与分歧，给出情景化的观察要点（而非买卖指令）。

闲聊或讨论非个股问题时，主控只安排 1-2 位相关专家回应，不会全员上场。

## 会话属性

主控会根据你的发言自动维护（侧栏「投资」分组可见）：

- `stock_watchlist`：你提出过的关注标的
- `stock_focus`：当前标的
- `stock_risk_preference`：你自述的风险偏好

## 合规声明

本世界所有内容仅供参考，**不构成投资建议**。分析基于公开免费接口（腾讯财经、东方财富、新浪财经）的查询结果，接口字段与可用性可能随上游调整变化；专家观点由大模型生成，可能存在错误。不承诺收益，不保证准确性，投资有风险，决策需自担。
