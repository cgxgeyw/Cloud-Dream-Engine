# 凡人修仙：小石村问道

这是一个从七玄门入门试炼开始的《凡人修仙传》人界篇早期同人世界包。玩家扮演原创角色陆谨，与同期的韩立、张铁一起进入七玄门，在凡人江湖与修仙界的边缘谨慎求生。

## 内容

- 桌面端三栏叙事界面，右侧使用通用 `side_panel_tabs` 展示地图、背包和持久化属性。
- 移动端安全区布局，地图、背包、装备、功法和修炼状态集中在行囊抽屉。
- 早期地图：镜州、小石村、彩霞山、七玄门山门、炼骨崖、外门弟子院、神手谷、百锻堂、野狼帮山道、太南小会。
- `attribute_schemas` 声明气血、体力、灵力、装备、功法和修炼等权威状态，新存档自动初始化。
- 世界主控读取当前属性并通过 `character_attribute_updates` 写回；背包、地图位置和在场人物使用框架原生会话状态，不建立 KV 副本。
- 界面不捆绑背景图；作者可后续向 `manifest.assets` 和 `ui_assets_config.local_scene_backgrounds` 增加自己的场景资源。

## 导入与制作

将 `manifest.json`、`world/`、`characters/` 和 `assets/` 直接压到 ZIP 根目录，再从应用的世界包导入入口导入。这个示例包使用 UI runtime 3，不依赖沙箱 JS 或世界 KV。
