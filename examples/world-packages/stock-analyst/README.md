# A股投研助手（单智能体）

一对一的 A 股投研工作台。报出股票名称或代码，研究员先调用行情、K 线、公告与快讯工具取到真实数据，再按六节输出一份完整报告。

与 `stock-council`（五位专家的多智能体议事厅）的区别：这里只有一个研究员，`service_mode` 为 `agent_chat`，没有世界主控。每回合 1–2 次模型调用，输出是结构化报告而非多人对话。

## 工具：随包内嵌（v8），无需单独导入

本包已按世界包 v8 格式内嵌全部行情工具定义（`tools.json`），**导入世界包即自动完成工具安装**（按 id upsert）。内嵌工具：

- `mcp-tool-stock-quote` — 实时行情（腾讯财经）
- `mcp-tool-stock-kline-daily` — 日 K 线（东方财富）
- `mcp-tool-stock-kline-daily-sina` — 日 K 线备用源（新浪财经，东财失败时自动改用）
- `mcp-tool-stock-announcements` — 公司公告（东方财富）
- `mcp-tool-market-news` — 财经快讯（新浪财经）

> 旧版应用（世界包 v7 及以下）不认识内嵌工具，需在「MCP 工具」页手动导入 `assets/tool-packs/stock-market-tools.json`；漏做不会导入失败，但运行时研究员取不到数据，会如实说明「未取到数据」。

## 输出格式

询问具体标的时固定六节：

```
【标的名 代码】
数据时间：<行情工具返回的时间>

■ 行情
■ 技术面
■ 基本面
■ 消息面
■ 风险提示
■ 结论

仅供参考，不构成投资建议
```

闲聊、问候或非个股问题不套用此格式，正常简洁作答。

## 会话属性

侧栏「投资」面板：

- **关注标的** — 你提出关注的自选股与指数
- **当前标的** — 本轮对话围绕的标的
- **风险偏好** — 你自述的偏好（保守 / 稳健 / 积极）

## 关于 max_tokens

`generation_params.max_tokens` 设为 8000。推理模型（如 deepseek-v4-flash）会把 token 预算先花在思考上，预算不足时正文为空、整回合失败。工具返回的 K 线与公告数据本身也占上下文，不要下调这个值。

## 合规声明

所有分析基于工具查到的公开数据，标注来源与时间。不承诺收益，不保证准确性，不预测确定性涨跌。仅供参考，不构成投资建议。
